# Route Studio · Windows 桌面版

解压 Windows 发布包后，双击 `RouteStudio\RouteStudio.exe` 即可使用，网页已内嵌在独立 Windows 窗口中。保留同目录的 `_internal` 文件夹，不能只移动一个 exe。打包版无需另装 Python；电脑仍需可用的 Edge WebView2 Runtime 和 Apple 设备通信支持。源码运行与打包见 [BUILD.md](BUILD.md)。

## 每次使用

1. 用 USB 连接 iPhone 并解锁，查看左下角 USB 卡片。
2. 打开“路线库”选择已保存路线，或者在“布设路线”导入/编辑 GPX，并点击“保存到路线库”。
3. 在“手机回放”点击“连接手机”。已有载入路线时，连接会发送起点；手机已连接时载入路线也会发送起点。
4. 设置配速，点击“保存参数”。可以用“收藏配置”保存一组常用参数，下次选择后再次保存参数即可应用。
5. 点击“开始移动”。暂停后可以改参数；结束时点击“停止并清除模拟”，确认手机恢复真实位置，再断开。

## 记忆内容

- 多条路线、路线名称和缩略预览。
- 常用配速及完整参数配置。
- 未完成草稿、地图位置、上次页面和回放参数。
- 每次回放的日期、路线、参数、模拟距离、回放时长和结束原因。
- 窗口大小。

数据保存在 `%LOCALAPPDATA%\RouteStudio`，与软件目录分开，移动或更新软件后继续使用。`memory.json` 是路线库、配置与历史；`session.json` 是上次载入路线和参数；`desktop.log` 是滚动日志。备份时先关闭软件，再复制此数据文件夹。不会自动连接手机或开始回放。

历史是本软件的模拟回放记录，不代表真实运动或第三方小程序记录。没有新增第三方记录提交功能或校验规避功能。

## USB 状态与中断处理

- “USB 已连接”：Apple usbmux 已发现手机，不等于定位服务已连接。
- “等待手机信任 / 请解锁 iPhone”：需要在手机上完成操作。
- “开发者模式未开启”：需要在 iPhone 上开启并完成重启确认；软件不会自动更改系统设置。
- “定位服务已连接”：定位服务连接成功，才可以回放。
- 拔线时停止回放，包括暂停状态；保存已有路线并记录中断。模拟位置是否清除无法在断线时保证。
- 重新接上后，若提示遗留定位，点击左下角“清除遗留定位”，等待几秒，再在手机地图确认真实位置恢复。重新接入不会自动开始回放。
- 检测 Apple 通信失败时显示检测异常，不把检测失败当作已拔线。

USB 使用约 1 秒的轮询，首次读取配对及开发者模式状态可能需要几秒。地图底图和地点搜索需要联网，已保存路线与坐标控制不依赖底图。

## 当前版本验证范围

已进行路线库/配置的保存和重开验证、最小窗口布局检查、原生 WebView2 启动及退出检查，以及 USB 插入、暂停时断开、重新插入、检测失败、意外退出恢复的自动测试。用户配合进行了真机 USB 连接、拔线、重新插入检测，三个状态均记录正确，配对和开发者模式读取成功。测试不向真机发送定位。

桌面版沿用原项目定位适配器，原项目源码未改写。此前普通地图真机定位与恢复已验证；本次桌面版的真机定位发送和微信小程序兼容性不据此算作已验证。

快捷键：`Ctrl+1/2/3` 切换工作台、路线库、历史；`Ctrl+S` 保存当前编辑路线到路线库。
